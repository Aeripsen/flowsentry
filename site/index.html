FlowSentry, live demo

An intrusion detector that says "I don't know" when it meets an attack it has never seen.

A network-attack classifier with a confidence knob. Below the knob it does not guess; it hands the flow to an analyst as unknown. Everything here is computed from 6,570 real network flows the model never trained on, from BCCC-UDP-QUIC-IDS-2025, the public dataset behind my accepted SECRYPT 2026 paper. Nothing is simulated.

Zero-day: an attack family the model never saw

Each round removes one attack family from training entirely, retrains, and then shows the model that family's flows. A closed-set model has to call them something, and mostly it calls them benign. How you can check this

  • The held-out flows come from a connection-grouped split: no UDP connection appears in both training and test. Predictions and confidences were computed once by make train && make demo-data and are downloadable above. The page applies the knob; it does not run the model in your browser.
  • Before this page deploys, CI runs tests/test_demo_data.py, which rebuilds the committed coverage-reliability curve, the binary PR-AUC of 0.9767 and the per-family confusion counts from these exact rows, and checks the zero-day means shown here against the committed summary.
  • The zero-day panel reads artifacts/zero_day_lofo.json as committed (make zero-day): seven retrains, four model arms, plus a shuffled-label control.
  • The data is a stratified sample of the public dataset: every flow of the seven rare families, with benign and UDP-RAW capped. Rare-family numbers rest on 52 to 100 test flows each.
  • It classifies stored flow records. It is not a live network tap, and nothing here ran on real traffic.
  • The two-stage design from the paper does not beat a single forest on this sample, and the README says so with the numbers.
